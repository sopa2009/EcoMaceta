¿Qué es EcoMaceta?

EcoMaceta es una maceta diseñada para cultivar diferentes tipos de plantas. Su característica principal es buscar una alternativa más responsable para cuando el producto ya no se utilice.

🎯 Público objetivo

Personas que tienen plantas en casa, estudiantes, jóvenes, familias y cualquier persona interesada en decorar sus espacios de una manera más amigable con el ambiente.

💡 Propuesta de valor

Una maceta atractiva, funcional y pensada desde el principio para disminuir residuos y fomentar el cuidado de las plantas.

💰 Precio

El precio dependería del tamaño y los materiales utilizados. La idea es mantener un precio accesible para estudiantes y familias.

🛒 Forma de venta

Se puede vender mediante redes sociales, pedidos directos y nuestra página web.

📱 Publicidad

Se pueden utilizar Instagram, TikTok y Facebook para mostrar nuestros diseños, plantas, personajes y consejos.

🚀 Lanzamiento

Para el lanzamiento se pueden publicar imágenes del producto, presentar a las mascotas y crear una promoción para los primeros compradores.

💚 Servicio postventa

Brindar recomendaciones para cuidar la maceta, resolver dudas y recibir comentarios de los clientes.

El comportamiento de una página web.

¿Qué es JavaScript?

JavaScript es un lenguaje de programación utilizado para agregar interactividad y comportamiento a las páginas web.


HTML crea la estructura, CSS se encarga del diseño y JavaScript permite que la página reaccione a las acciones del usuario.

✨ jQuery

Una librería que facilita el uso de JavaScript.

¿Qué es jQuery?

jQuery es una librería de JavaScript que nació para hacer más sencilla la manipulación de elementos, eventos, animaciones y efectos en páginas web.


Una de sus características más conocidas es el uso del símbolo $ para seleccionar elementos. 

$("#mensaje").fadeIn();

$("#menu").slideToggle();

Ventajas

  • Sintaxis sencilla.
  • Facilita algunas animaciones.
  • Fue muy útil para compatibilidad entre navegadores.

Desventajas

  • JavaScript moderno puede hacer muchas de estas tareas sin jQuery.
  • Puede ser innecesario en proyectos pequeños.

📦 JSON

Datos organizados para que las aplicaciones puedan comunicarse.

¿Qué significa JSON?

JSON significa JavaScript Object Notation. Es un formato utilizado para organizar y transmitir información entre aplicaciones y servidores.

Objeto JavaScript 

const planta = {

    nombre: "Cactus",

    color: "verde",

    precio: 8

};

JSON 

{

    "nombre": "Cactus",

    "color": "verde",

    "precio": 8

}

🌐 Web Hosting y Dominios

¿Cómo llega una página web a Internet?

☁️ Web Hosting

Es el servicio que permite guardar los archivos de una página web en un servidor para que otras personas puedan acceder a ella mediante Internet.

📌 Tipos de Hosting

  • Hosting compartido.
  • VPS.
  • Hosting en la nube.

▲ Vercel

Vercel permite desplegar proyectos web conectando un repositorio de código para que pueda estar disponible públicamente en Internet.

🔗 Dominio

Un dominio es el nombre que utilizamos para encontrar una página web.


ecomaceta.com

🌎 TLD

Es la parte final de un dominio.


.com   .net   .org

📂 Subdominio

Es una sección adicional de un dominio.


blog.ecomaceta.com

🔄 Propagación DNS

Cuando se conecta un dominio con un sitio web, los cambios de DNS pueden tardar un tiempo en actualizarse y llegar a diferentes servidores.

Dominio → DNS → Servidor → Página web
