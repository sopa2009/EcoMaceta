🌱 PRODUCTO

Conoce EcoMaceta

EcoMaceta es una maceta pensada para personas que disfrutan tener plantas y que también quieren tener una mayor conciencia sobre el cuidado del medio ambiente.

Público objetivo

Está dirigida principalmente a estudiantes, familias, personas que tienen plantas y personas interesadas en productos ecológicos.

Propuesta de valor

EcoMaceta busca combinar diseño, utilidad y conciencia ambiental en un mismo producto.

🌱

Ecológica

Busca disminuir el impacto que puede tener una maceta cuando deja de utilizarse.

💧

Práctica

Está pensada para utilizarse fácilmente en el cuidado diario de las plantas.

🌎

Responsable

Promueve una mayor conciencia sobre el cuidado del planeta.

💻 TECNOLOGÍA

JavaScript Vanilla

JavaScript es un lenguaje de programación que permite agregar interacción y comportamiento a las páginas web.

HTML

Se utiliza para crear la estructura de la página.

CSS

Se utiliza para el diseño y la apariencia.

JavaScript

Agrega interacción y comportamiento.

Variables 

let nombre = "EcoMaceta";
let precio = 10;

Funciones 

function saludar() {
    alert("Hola desde EcoMaceta");
}

Eventos

Los eventos permiten que la página responda a acciones del usuario, como hacer clic en un botón.

⚙️ JAVASCRIPT

jQuery

jQuery es una biblioteca de JavaScript que facilita algunas tareas comunes al desarrollar páginas web.

¿Para qué sirve?

Puede facilitar el trabajo con elementos HTML, eventos y efectos.

Ejemplo 

$("#boton").click(function() {
    alert("Hola");
});

Ventaja

Tiene una sintaxis sencilla para algunas tareas.

Efectos

Puede utilizar efectos como fadeIn(), fadeOut() y slideToggle().

Símbolo $

Se utiliza frecuentemente para trabajar con elementos de la página.

📦 DATOS

JSON

JSON significa JavaScript Object Notation. Es un formato utilizado para almacenar y transportar información.

Ejemplo 

{
    "nombre": "EcoMaceta",
    "precio": 10,
    "ecologica": true
}

Clave y valor

JSON organiza la información mediante pares de clave y valor.

Comunicación

Puede utilizarse para enviar y recibir información entre una página web, un servidor o una API.

🌐 INTERNET

Web Hosting y Dominios

¿Qué es un hosting?

Es un servicio que permite almacenar los archivos de un sitio web para que puedan estar disponibles en Internet.

🏠

Compartido

Varios sitios utilizan recursos del mismo servidor.

🖥️

VPS

Proporciona recursos más independientes.

☁️

Cloud

Utiliza recursos distribuidos en la nube.

Vercel

Vercel permite publicar proyectos web y resulta útil para sitios estáticos y aplicaciones web.

Dominio

Es el nombre o dirección que las personas utilizan para entrar a un sitio web.

DNS

El DNS ayuda a conectar un dominio con el servidor donde está alojado el sitio.
